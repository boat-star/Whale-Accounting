鲸鱼记账 · 使用说明

一个只在你电脑里运行的记账本。不注册、不联网、不偷看你的账单。

Windows 11 数据存本地 键盘记账 免费

1先把软件装上

  1. 找到发你的那个安装包，文件名是 鲸鱼记账-1.0.0-安装版.exe，双击它。
  2. 如果系统弹出蓝色的「Windows 已保护你的电脑」，点「更多信息」，再点「仍要运行」。这是因为软件没有买数字签名证书，不是病毒。
  3. 一路点「下一步」就行。它只会装给你当前用户，不需要管理员密码。
  4. 装好后，桌面和开始菜单会出现一只蓝头发的鲸鱼娘，双击打开。
如果杀毒软件报毒：把它加入信任列表即可。这个程序没有任何联网代码，断网也能正常记账。

2第一次打开，你会看到这些

软件已经帮你准备好了 4 个账户（现金、微信、支付宝、银行卡）和一套常用分类（餐饮、交通、购物、居住……），不用从零设置。

概览今天花了多少、本月支出、分类占比、预算还剩多少
明细所有流水按日期排好，点一下就能改或删
报表按月和按年看趋势、分类排行、和上个月对比
预算设一个月度上限，超了会提醒你
账户管钱放在哪，信用卡欠款也能记
分类 / 设置自己加分类、导入账单、备份数据

3记第一笔账（三种方式）

方式一：最快，键盘

在任何页面按 Ctrl + N，弹出记账窗口。光标已经在金额栏，直接敲数字，按 Enter 保存，窗口自动关掉。

方式二：点按钮

左下角蓝色的「记一笔」，或者概览页那个按钮。

方式三：按 N 键

不在输入框里的时候，直接按字母 N 也能唤起。

金额栏可以直接算数。比如买了 12.5 和 8 块两样东西，就输入 12.5+8，它会记成 20.50，不用自己心算。

4几个必须搞懂的概念

支出 / 收入 / 转账，别选错

  • 支出：钱花出去了，比如吃饭、打车。
  • 收入：钱进来了，比如工资。
  • 转账：钱只是从你左边口袋到右边口袋，不算花钱。用银行卡还信用卡、微信提现到银行卡，都选转账。
最常见的错误：把「还信用卡」记成支出。这样你的月度支出会凭空多出一大笔。正确做法是在「账户」页点转账图标，从银行卡转到信用卡。

信用卡和借款，余额填负数

比如信用卡欠了 2000，新建账户时初始余额填 -2000。这样「净资产」才是真实的钱。

余额对不上怎么办

去「账户」页点对账，填上银行 App 里看到的真实余额。软件会自动记一笔「余额调整」，把差额补上，不会弄乱你原来的账单。

5把支付宝 / 微信的账单导进来

  1. 手机上导出账单：支付宝「我的 → 账单 → 右上角 → 开具交易流水证明」，微信「我 → 服务 → 钱包 → 账单 → 常见问题 → 下载账单」。
  2. 把收到的 CSV 文件传到电脑上。
  3. 打开软件「设置 → 导入账单」，先选导入到哪个账户，再点「选文件」。
  4. 导完去「明细」看一眼，分类可能需要手动改一下，因为账单里没有分类信息。
重复导入不会重复记账。同一个文件导两次，第二次会自动跳过。

6备份：唯一需要你养成的习惯

数据存在你自己的电脑里，好处是没人能看，坏处是电脑坏了就没了。

所以：每周点一次「设置 → 立即备份」，或者干脆每月把备份文件夹复制到网盘或 U 盘。

数据位置：%APPDATA%\com.whaleledger.app\whale.db
备份位置：%APPDATA%\com.whaleledger.app\backups\

把上面这段路径粘贴到文件资源管理器的地址栏，回车就能打开。

卸载软件前，一定先备份或导出 CSV。卸载程序会问你要不要删数据，选「否」更安全。

7常见问题

Q：打开是白屏 / 一闪就没了？
A：先重启电脑再试。仍然不行的话，把 %TEMP%\whale-main.log 这个文件发给开发者，里面记录了启动过程。

Q：能把数据换到另一台电脑吗？
A：可以。「设置 → 导出全部」得到一个 CSV，在新电脑上导入。或者直接复制 whale.db 文件到新电脑的同一路径。

Q：会偷偷联网吗？
A：不会。程序没有任何联网代码，把网线拔了照样用。

Q：安装包有点大（约 150 MB）？
A：内置了完整的浏览器内核，所以体积偏大。换来的是不依赖系统组件、在哪台 Win11 上都能跑。

Q：记账记错了想删掉？
A：在「明细」里找到那一行，鼠标移上去，右边会出铅笔和垃圾桶图标。
