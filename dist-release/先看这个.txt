鲸鱼记账 1.0 —— 先看这个
========================================

一、怎么装（推荐）

  双击「鲸鱼记账-1.0.0-安装版.exe」，一路点「下一步」。
  如果弹出蓝色的「Windows 已保护你的电脑」：
      点「更多信息」→ 点「仍要运行」。
  这是因为软件没有购买数字签名证书，不是病毒。

  装完后，桌面会多一只蓝色小鲸鱼，双击就能打开。
  也可以从开始菜单里找「鲸鱼记账」。


二、怎么用（三步）

  1. 打开软件，按 Ctrl + N（或者点左下角「记一笔」）
  2. 敲金额 → 选分类 → 按回车
  3. 完事。窗口会自动关掉，回到你原来的工作

  金额那一栏可以直接写算式，比如 12.5+8，会记成 20.50。


三、详细说明

  双击「使用说明.html」，会用浏览器打开，
  里面有截图、转账怎么记、信用卡怎么填、账单怎么导入、
  数据怎么备份，以及常见问题。


四、不想安装？

  解压「鲸鱼记账-1.0.0-绿色版.zip」到任意文件夹，
  双击里面的「鲸鱼记账.exe」即可使用。
  绿色版不写注册表、不在桌面留快捷方式，删文件夹就等于卸载。


五、你的数据在哪

  位置：%APPDATA%\com.whaleledger.app
  里面 whale.db 就是你的账本，backups 文件夹是备份。

  把这个路径粘到文件资源管理器的地址栏，回车就能打开。

  重要：卸载程序会问你要不要删数据，默认「否」。
  想换电脑，先「设置 → 立即备份」，再把 whale.db 复制过去。


六、这个版本能做什么

  记账      支出 / 收入 / 转账，金额支持算式，日期可选
  分类      两级分类，可自己加、换图标，删除只是归档不丢历史
  账户      现金、储蓄卡、信用卡、第三方支付、投资、借款
  预算      月度总预算 + 分类预算，超支会变色提醒
  报表      分类占比、每日趋势、按月按年对比、分类排行
  明细      按日期分组，点一行就能改，删除后余额自动还原
  导入      支付宝 / 微信 / 银行导出的 CSV，重复导入不会重复记账
  导出      导出 CSV（Excel 可直接打开，中文不乱码）
  备份      一键备份数据库，可看历史备份列表
  界面      深色模式、金额千分位、键盘全流程操作


七、快捷键

  Ctrl + N        记一笔
  Enter           保存并关闭
  Esc             取消
  Ctrl + 1 ~ 7    切换左侧页面
  N               光标不在输入框时，直接记一笔


八、遇到问题

  打不开 / 白屏
      先重启电脑再试。仍然不行的话，把
      %TEMP%\whale-main.log 这个文件发给开发者。

  杀毒软件报警
      加入信任即可。程序没有联网代码，断网也能用。
